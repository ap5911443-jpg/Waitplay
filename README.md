# WaitPlay Website 🎮

> The official marketing website for **WaitPlay** — the zero-interruption gaming companion for AI coding agents.  
> Designed following the warm editorial design system of [Wispr Flow](https://wisprflow.ai/) (`design.md`).

---

## ✨ Design Language & Tokens

- **Warm Cream Canvas:** `#FFFFEB` dominant canvas with `#E4E4D0` subtle panels.
- **Editorial Typography:** `EB Garamond` display headings with italic emotional accents.
- **Clean UI & Body Typography:** `Figtree` regular to semibold.
- **Lavender Primary Action:** `#F0D7FF` with `#1A1A1A` text and gentle hover lift.
- **Forest Green Contrast Sections:** `#034F46` for Speed Comparison and Zero-Telemetry Security.
- **Orange Accents:** `#FFA946` for metrics and status badges.

---

## 🚀 Quick Start

### 1. Install Dependencies

```bash
npm install
```

### 2. Start Development Server

```bash
npm run dev
```
Open [http://localhost:5250](http://localhost:5250) in your browser.

### 3. Build for Production

```bash
npm run build
```

### 4. Preview Production Build

```bash
npm run preview
```
